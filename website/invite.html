How it works

  1. Already have Peekaboo? Tap Open in Peekaboo, then tap Add.
  2. New to Peekaboo? Get the app and make your account. Then come back to this page and tap Open in Peekaboo.
  3. Button not working? Open Peekaboo, go to your profile → ⚙️ Settings → Invite friends, and type the code under Got a code from a friend?
  4. If Peekaboo says it can't find the page, close the app completely and open it again so it updates, then tap Open in Peekaboo again.
